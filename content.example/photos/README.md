Put photos here (JPEG, PNG or WebP) and reference them from `gift.toml` as `photos/<file>`.

`seal` re-encodes every photo: max 1600 px on the long edge, JPEG quality 85, EXIF orientation applied.
**All metadata (GPS, camera, timestamps) is dropped.** Originals are never copied anywhere.

iPhone HEIC: export as JPEG first (Photos → File → Export, or "Most Compatible" under Settings → Camera → Formats).
